# Software Engineering in the AI Era / Engenharia de software na era da IA

This repository holds a report on how software engineering changes in the age of AI, plus an interactive website built from it.

- [`engenharia_de_software_na_era_da_ia.md`](engenharia_de_software_na_era_da_ia.md): the original report, in Brazilian Portuguese
- [`software_engineering_in_the_ai_era.md`](software_engineering_in_the_ai_era.md): the English translation
- [`website/`](website/): the interactive, bilingual course site (Astro, React, GSAP, three.js). See [`website/README.md`](website/README.md)

GitHub Actions builds the site and publishes it to GitHub Pages on every push to `main`.
